# ユースケース一覧（ユーザー視点）

## 目的

本ドキュメントは、`D-01` 〜 `D-12` と `docs/README.md` を統合し、ユーザーがこのアプリで「何ができるか」を利用シナリオ単位で整理したもの。

## 想定ユーザー

- 論文を検索して保存し、継続的に読み進めたい研究者・学生
- テーマ単位で論文を整理し、関連関係を把握したいユーザー
- メモやキーワード管理を使って、後から再利用しやすい知識ベースを作りたいユーザー
- TeX/BibTeX と連携し、執筆作業までつなげたいユーザー
- 自然言語でタスクを依頼し、作業を自動化したいユーザー

## エンドツーエンド利用フロー

1. サインインして利用を開始する（D-01）
2. 論文を検索し、結果を再整理して候補を絞る（D-04）
3. 気になる論文をライブラリに保存する（D-03）
4. 保存論文に対して PDF 取り込みを行い、読解支援を有効化する（D-05, D-09）
5. メモ・キーワードで論文知識を構造化する（D-06, D-08）
6. プロジェクトを作り、論文を束ねてグラフで関係を俯瞰する（D-02, D-07, D-12）
7. 必要に応じて TeX ワークスペースで執筆・コンパイルする（D-10）
8. 一部作業を AI エージェントに自然言語で委譲する（D-11）

## ユースケース詳細

### UC-01: ログインして自分の作業領域を使う

- ユーザーは Email/Password または Google でログインできる
- ログイン後、自分のプロフィール情報を取得・更新できる
- 以降の API は認証済みユーザーのデータだけを対象に動作する
- 関連ドメイン: `D-01`

### UC-02: 論文を探す・候補を整理する

- キーワード検索で論文候補を取得できる
- 検索結果を LLM で「重要論文ハブ型」に再整理し、読み始める順序を決められる
- 検索結果から直接「保存（Like）」につなげられる
- 関連ドメイン: `D-04`（+ `D-04-search-clustered-results`）, `D-03`

### UC-03: 気になった論文をライブラリに保存する

- 論文を Like トグルで自分のライブラリへ追加/解除できる
- 保存済み論文を一覧・詳細で確認できる
- 保存を起点に、後続のメモ・読解支援・グラフ機能に接続できる
- 関連ドメイン: `D-03`

### UC-04: PDF を取り込み、読解可能な状態にする

- 論文 PDF をアップロードし、取り込みジョブを起動できる
- 取り込みは `queued/running/completed/failed` の状態で進行管理される
- 完了後はチャンク化・埋め込み・インデックス化されたデータを読解支援で利用できる
- 関連ドメイン: `D-05`, `D-09`

### UC-05: 論文を読みながら要点を理解する

- 目次とチャンク単位で内容を段階的に読める
- 選択テキストの解説生成ができる
- 重要箇所をハイライトとして保存・再取得できる
- ライブラリ全体を対象に RAG 質問できる
- 関連ドメイン: `D-09`

### UC-06: メモを蓄積して知見を残す

- 手動または保存動作に連動してメモを作成できる
- メモ一覧・詳細・更新・削除ができる
- メモには参照情報（論文・URL・識別子）を紐付けて管理できる
- 関連ドメイン: `D-08`

### UC-07: キーワードで論文をタグ管理する

- キーワードを作成・更新・削除できる
- 論文ごとにキーワードを付与/解除できる
- 論文内容からキーワード候補を自動提案し、適用できる
- 関連ドメイン: `D-06`

### UC-08: プロジェクト単位で論文を整理する

- 研究テーマごとにプロジェクトを作成できる
- プロジェクトへ論文を追加/削除し、一覧で管理できる
- プロジェクトの基本情報（タイトル、説明など）を更新できる
- 関連ドメイン: `D-02`

### UC-09: 論文間のつながりをグラフで把握する

- ある論文の関連論文を取得できる
- プロジェクト内の論文関係をグラフで可視化できる
- ライブラリ全体のグラフを `embedding / keyword / hybrid` の接続モードで取得できる
- 関連ドメイン: `D-07`

### UC-10: キーワード起点でライブラリ内の関連論文を見つける

- 指定論文に対して、共通キーワードを軸にライブラリ内の関連候補を取得できる
- どのキーワードで結びついたかを説明付きで確認できる
- 関連ドメイン: `D-12`, `D-06`

### UC-11: TeX ワークスペースで執筆作業を進める

- プロジェクト配下で TeX ファイルの一覧・取得・保存・削除・アップロードができる
- コンパイル実行と PDF プレビュー取得ができる
- 論文整理から執筆ワークフローへそのまま移行できる
- 関連ドメイン: `D-10`, `D-02`

### UC-12: AI エージェントに作業を依頼する

- 自然言語で依頼を送ると、エージェントが計画生成・実行を行う
- 実行は allowlist に限定され、安全に制御される
- 確認が必要なアクションは `pending_actions` として返される
- 関連ドメイン: `D-11`

## 機能マップ（D-01〜D-12）

| ドメイン | ユーザーができること |
| --- | --- |
| D-01 認証/ユーザー | ログイン、ユーザー情報の取得/更新 |
| D-02 プロジェクト | プロジェクト作成・編集・削除、論文紐付け |
| D-03 ライブラリ | 論文保存（Like）、保存論文の一覧/詳細 |
| D-04 検索 | 論文検索、LLM による結果再整理 |
| D-05 取り込み | PDF 取り込み起動、処理ステータス管理 |
| D-06 キーワード | キーワード CRUD、論文タグ付け、候補提案 |
| D-07 関連グラフ | 論文関連取得、プロジェクト/全体グラフ可視化 |
| D-08 メモ | メモ CRUD、参照情報付きノート管理 |
| D-09 読解サポート | 目次/チャンク閲覧、解説生成、ハイライト、ライブラリ質問 |
| D-10 TeX/BibTeX | TeX ファイル操作、コンパイル、PDF プレビュー |
| D-11 AIエージェント | 自然言語による作業依頼、計画実行、確認付き実行 |
| D-12 キーワード関連 | キーワード軸のライブラリ内関連論文発見 |
